## Summary
建立管理者帳號鑑權流程與儀表板存取控管，確保只有授權使用者可檢視與操作問卷資料。

## Why
目前缺乏登入與權限管理，無法在部署前滿足醫師儀表板的安全需求。

## Scope
- 定義管理者帳號資料模型與安全的密碼儲存方式。
- 實作登入 API（Session 或 JWT）與失敗節流機制。
- 以中介層或守衛保護儀表板相關路由與 CRUD API。
- 針對敏感操作新增基本審計日誌與錯誤處理。
- 撰寫必要的設定說明與管理者帳號啟用流程文件。

## Out of Scope
- 重新設計儀表板前端介面或視覺風格。
- 非管理者角色的權限系統擴充。
- 第三方身份驗證（如 OAuth、SAML）的整合。

## Acceptance Criteria
- 管理者可使用配置的帳密登入並獲得有效憑證。
- 未授權或過期請求被拒絕並回傳適當錯誤狀態。
- 儀表板頁面與相關 API 只允許已驗證的管理者存取。
- 單元與整合測試涵蓋登入成功、失敗與保護路由情境。

## Implementation Steps
1. 建立管理者帳號資料模型與種子流程，採用安全哈希儲存密碼。
2. 實作登入 API 與 Token/Session 發放、續期與失效處理。
3. 新增保護儀表板與 CRUD API 的中介層，回傳一致的錯誤格式。
4. 實作基本審計日誌並覆蓋登入、資料操作行為。
5. 撰寫設定說明，包含環境變數、初始帳號與安全建議。

## Test/Validation
- 撰寫登入與授權的單元／整合測試。
- 使用 Postman 或自動化測試流程驗證典型與異常登入案例。
- 本地啟動儀表板並驗證未登入狀態下無法存取任何管理 API。
