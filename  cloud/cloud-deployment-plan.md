# 雲端部署計劃

## 專案概述
本專案需部署至雲端，提供問卷填寫與風險評估的前端介面，以及供醫療人員使用的管理儀表板。部署策略以 GCP Cloud Run 為主，確保前後端容器化服務與雲端資料庫之間的整合與安全存取。

## 角色與主要需求
- **使用者（問卷填寫者）**：透過公開網址完成問卷並取得風險評估結果。
- **管理者（醫療專業人員）**：登入後端儀表板，檢視並管理使用者提交的問卷資料，具備增刪改查能力。

## 核心流程
### 使用者旅程
1. 訪問部署後的前端網址。
2. 瀏覽問卷導覽並完成問卷填寫。
3. 取得對應的風險評估結果。

### 管理者旅程
1. 訪問醫師儀表板網址（部署後提供）。
2. 導向登入頁面並完成帳密驗證。
3. 進入儀表板瀏覽歷史資料，並可對問卷紀錄進行增刪改查操作。

## 系統需求與約束
- 前端與後端需容器化，並於 Cloud Run 上分別部署服務，維持清楚的 API 介面。
- 後端須整合雲端資料庫（例如 Cloud SQL 或相容方案），並確保儀表板可讀寫問卷資料。
- 必須實作管理者登入功能，並以權限控管保護儀表板，部署前須完成本地驗證。
- 需規劃環境變數與機密管理（例如使用 Secret Manager）以保護敏感資訊。
- 維持日誌與監控管道，以便維運時追蹤系統狀況與查核行為。

## 里程碑與交付物
### M1 後端鑑權與資料安全強化
- 定義管理者帳號模型與登入流程。
- 實作登入 API 與 Session/JWT 機制，保護儀表板路由。
- 為儀表板增設權限檢核與必要的錯誤處理／審計日誌。

### M2 服務容器化與本地整合
- 為前端與後端建立 Dockerfile 與本地 docker-compose 配置。
- 確認容器間網路互通，並於本地完成問卷與儀表板流測試。
- 撰寫部署所需環境變數與設定檔指引。

### M3 雲端基礎設施配置
- 建立 Cloud Run 服務、對應的雲端資料庫與網路設定（VPC Connector 或私有連線）。
- 設置身分與存取管理（IAM），確保服務與資料庫的授權正確。
- 規劃環境同步（dev/staging/prod）與機密管理流程。

### M4 部署與驗證
- 部署前後端容器至 Cloud Run，綁定對外網址。
- 執行端對端流程驗證（問卷填寫、登入儀表板、資料 CRUD）。
- 建立即時回滾與監控流程，並撰寫部署報告。

## 成功驗證指標
- 使用者可於雲端環境完成問卷並取得評估結果，關鍵 API 回應時間符合服務等級期待。
- 管理者可於雲端儀表板安全登入並操作資料，權限控管與日誌完整。
- 部署流程可重複執行（CI/CD 或文件化程序），並有明確的故障復原策略。
